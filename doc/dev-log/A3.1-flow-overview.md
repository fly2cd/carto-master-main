# A3.1 通用专题制图流程全景

> 更新：2026-11-14 | 基于 `scenario-capabilities.yaml` v1.7.0

## 1. 体系概览

```
                         A3.1 通用专题制图
                    general_thematic_mapping
                              │
              ┌───────────────┴───────────────┐
              │                               │
        栅格变体 (raster)                 矢量变体 (vector)
    template: 3.0.0                    template: 4.0.0
    renderer: rasterio-matplotlib      renderer: matplotlib-vector
    authoring: general-thematic        authoring: general-vector
              │                               │
              └───────────────┬───────────────┘
                              │
              共用：状态机 / 审批 / 预览 / 冻结 / 检查 / 交付
```

**关键原则**：
- 一个业务场景，一个能力档案 `general-thematic-mapping@5.0.0`
- 栅格/矢量是 `geometry_variants` 数据适配变体，共享段只声明一遍
- 几何由请求显式声明，不按模板版本号推断
- `production_enabled: false`，非生产准入

## 3. 设计修订支线 (revision)

```
  compile ──→ preview ──→ freeze
     │            │           │
     └──── 冻结前可提交 DesignRevisionProposal ────┐
                                                    │
  ① revision-brief → 输出完整修订 MapBrief          │
  ② 新 G1 审批该 MapBrief                           │
  ③ revise → 返回新 request_path                    │
  ④ 新方案写入 revisions/rN/，旧路径不变             │
  ⑤ 重新 compile → preview → freeze                 │
```

- 冻结后**不能**在原运行上修改设计，须新建运行
- 受累计修订预算约束
- 旧 G2 不批准新预览

## 4. 代码执行路径

### 4.1 CLI 入口

```
carto generate-map <step> --request <path>
```

单一步骤通过 `--help` 查看参数。

### 4.2 请求分派

```
skills/carto-agent/scripts/carto.py                   # CLI 入口
  └→ carto_core/cli.py                                # 子命令路由
      └→ carto_core/workflow/map_generation.py        # MapGenerationWorkflow
          ├→ intake()                                 # 步骤 ①
          ├→ brief()                                  # 步骤 ②
          ├→ compile()                                # 步骤 ③
          ├→ preview()                                # 步骤 ④
          ├→ revision_brief() / revise()              # 设计修订
          ├→ freeze()                                 # 步骤 ⑤
          ├→ render()                                 # 步骤 ⑥
          ├→ check()                                  # 步骤 ⑦
          ├→ review()                                 # 步骤 ⑧
          ├→ deliver()                                # 步骤 ⑨
          ├→ status() / retry() / receipts()          # 辅助
          └→ delivery_status()                        # 查询交付状态
```

### 4.3 几何分派（栅格 vs 矢量）

```
carto_core/scenarios/general_dispatch.py
  │
  ├→ geometry_of_request(request) → "raster" | "vector"
  │
  ├→ GeneralDataPreparer
  │    ├→ raster: general_thematic.GeneralThematicDataPreparer
  │    └→ vector: general_vector.GeneralVectorDataPreparer
  │
  ├→ GeneralPlanner
  │    ├→ raster: general_thematic.GeneralThematicPlanner
  │    └→ vector: general_vector.GeneralVectorPlanner
  │
  ├→ GeneralCandidateCompiler
  │    ├→ raster: general_thematic.GeneralThematicCandidateCompiler
  │    └→ vector: general_vector.GeneralVectorCandidateCompiler
  │
  └→ GeneralAuthor (模板创建)
       ├→ raster: general_thematic.GeneralThematicAuthor
       └→ vector: general_vector.GeneralVectorAuthor
```

### 4.4 compile 内部调用链（以栅格为例）

```
MapGenerationWorkflow.compile()
  │
  ├→ TemplateRepository.discover()
  ├→ ProjectTemplateInstaller.install()
  │
  ├→ MapDataPreparer.prepare()
  │    └→ GeneralThematicDataPreparer.prepare()
  │         ├→ BundlePreparer.prepare_request()        # 复用已冻结的准备工作证据
  │         └→ RasterPreparationService
  │              └→ skills/.../raster_preparation.py
  │
  ├→ MapPlanner.build()
  │    └→ GeneralThematicPlanner.build()
  │         ├→ ScenarioRegistry.for_template()
  │         ├→ LayoutResolver.resolve()
  │         ├→ build_page_bindings()                    # compiler/page_bindings.py
  │         └→ thematic.raster_views()
  │
  └→ MapCandidateCompiler.compile()
       └→ GeneralThematicCandidateCompiler.compile()
            ├→ RasterPortrayalCompiler.compile()         # compiler/raster_portrayal.py
            ├→ compile_page_request()                   # compiler/raster_page_contract.py
            └→ RasterSceneCompiler.compile()            # compiler/raster_scene.py
                 └→ 输出 RenderScene (renderer_id=rasterio-matplotlib-page)
```

### 4.5 渲染链

```
preview / render
  │
  ├→ MapPreviewService (预览)
  │    └→ adapters/static_page_renderer.py             # 消费 scene + bundle
  │         └→ Rasterio + Matplotlib → PDF + PNG
  │
  └→ FormalMapRenderService (正式渲染)
       └→ adapters/formal_renderer.py                  # 几何分派
            ├→ raster: RasterPageRenderer              # 同 static_page_renderer 内核
            └→ vector: VectorPageRenderer
       └→ 签发 FormalRenderReceipt (HMAC + 环境指纹)
```

### 4.6 终检与交付

```
check → FinalMapCheckService.inspect()
  │   11 项自动检查（外观/模板/布局/渲染/输出/数据/编码）
  │
review → 签 approve-product-review
  │   冻结 ProductReview + DeliveryManifest
  │
deliver → MapDeliveryService.deliver()
  │   G3 审批验证 → 隔离 staging → 原子提交 → DeliveryReceipt
```

## 7. 输入模型

### 栅格输入

```yaml
geometry: raster
source_bindings:
  - role: classified_surface
    source_ref: {id, version, digest}
    path: "data/classified.tif"
    field_bindings:
      - semantic_role: category-label
        source_field: category_value
prepared_raster_bindings:
  - ...  # 已澄清的分类合同引用
panels:
  - id: view-r1-c1
    source_id: main-raster
    title: "面板标题"
    design:
      geometry: raster
      kind: categorical
      measurement: nominal
      palette_source: prepared
```

### 矢量输入

```yaml
geometry: vector
vector_sources:
  - source_id: regions
    role: thematic-features
    format: geojson             # 或 shapefile
    crs: EPSG:4326
    files: [...]
    attribute_join:             # 可选
      source_id: indicators
      path: "data/attributes.csv"
      geometry_key: code
      table_key: code
      fields:
        - {column: pop, field: population, value_type: number}
      coverage: exact
      missing_policy: reject
vector_panels:
  - id: view-r1-c1
    source_id: regions
    title: "人口密度"
    design:
      geometry: polygon
      kind: choropleth           # 或 categorical / proportional
      measurement: density
      field: population
      normalization:
        denominator_field: area
        scale: 1
      classification:
        method: equal-interval   # 或 manual
        class_count: 5
      symbols: [...]
      missing: {policy: reject}
```

### 支持的表达类型

| 表达 | 几何 | 本期范围 | 拒绝 |
|---|---|---|---|
| categorical (类别) | polygon/point | 显式类别+标签+颜色 | 重复/歧义/未声明值 |
| choropleth (分级设色) | polygon | 等距/手工断点，密度/比率 | 总量冒充密度、非有限值 |
| proportional (比例符号) | point | 面积比例半径 | 负数/越界/钳位伪造 |
| raster categorical | raster | 已分类 TIFF + CSV 合同 | 未定义类别/缺颜色 |

## 9. 关键约束

| 维度 | 约束 |
|---|---|
| **输出** | A4 横版 297×210mm, 300dpi, 3508×2480px, PDF+PNG |
| **布局** | 网格 1×1 / 1×2 / 2×2，frame 互不重叠 |
| **图例** | 独立或共享（共享需一致表达/度量/比例） |
| **CRS** | 必须一致且匹配模板，不做隐式重投影 |
| **栅格** | 仅消费已确认类别+配色，nearest 重采样，单层 |
| **矢量** | 点/面，一对一属性连接，不做栅矢混排 |
| **字体** | Noto Sans SC，内嵌标记/字形覆盖验证 |
| **安全** | G1/G2/G3 独立审批核验；operator ≠ approver |
| **交付** | 白名单：map.pdf, map.png, README.md, manifest, checksums.sha256 |

## 10. create-template 模板创建（并行链路）

```
analyze → brief → author → validate → publish
   │        │        │         │          │
   │       T1       │    合成样张渲染    TP
   │     审批        │    冻结场景/回执  审批
   │                 │
            生成闭合 draft 包
            不含业务数据/敏感坐标
```

- `validate` 在受信验证上下文内渲染合成样张（从包内图例样本派生确定性合成栅格/矢量）
- `publish` 重新核验冻结证据并消费精确 TP
- 模板版本升级须重新验证发布，旧锁不自动迁移
- 模板创建/发布审批 ≠ 地图生成审批
