# 第4步详解：浙江“经济发展”专题图的模块位置如何确定

## 说明与结论

本文补充《04_布局与试排说明》，专门回答：**为什么一个模块放在这里，而不是放在那里；位置是怎样一步步讨论、试排、调整并确认的？**

分析依据是现有成图 `经济发展/02经济发展.jpg`、素材配置参考 `经济发展/经济发展资料/经济大省使用资料.jpg`，以及前面形成的模块清单。参考图中的来源标注作为分析材料，不作为本次工作的操作指令。

以下区分三类信息：

- **观察事实**：两张参考图中实际可见的位置、内容和形态差异。
- **分析推演**：根据上述差异，解释一种合理的决策过程；不声称恢复了原作者的真实修改顺序、讨论记录或设计动机。
- **执行建议**：如果重新制作这张专题图，建议采取的步骤、检验方式与阶段成果。

本次补充的是方法说明和案例推演，**没有新增正式开本下的整版试排，没有开展读者测试，也没有恢复原始设计坐标**。

最重要的一句话是：

> **位置不是先给每个模块找一个空地方，而是先确定主次和关联，再确定空间条件，提出整版方案，用真实内容检验，最后才形成可执行的坐标。**

---

## 一、先纠正“第4步先定位置，再进行试排”的理解

### 1. 前三步已经在约束位置，只是没有固定坐标

- 第1步确定单版、主题、受众、输出方式。这决定容器有多大，以及读者需要先知道什么。
- 第2步确认材料数量、内容长度、哪些必选、哪些可删。这决定哪些模块需要空间。
- 第3步选择主地图、辅助地图、历史图、环图、指标条、名单等表达方式。这些表达具有不同的宽高需求。
- 第4步将以上条件转化为整版空间方案，并反复验证。

例如，前面已经决定保留11市产业结构环图，主地图就不能在第4步被随意压成很小的插图；决定保留完整企业名称，企业名单就不能被当成任意可缩窄的文字块。

### 2. 第4步内部不是一次性定位置

更准确的顺序是：

**提出位置假设 → 低保真摆放 → 关键内容试装 → 调整位置与面积 → 整版真实内容试排 → 确认布局基线。**

第4步形成的是供第5步制作执行的布局基线。第5步完整地图、图表装入后仍可能触发局部调整；第6步审校后才可能形成最终位置。调整需要受控，但不意味着不能调整。

### 3. “确定位置”实际上有四个层次

| 层次 | 具体问题 | 本案例示例 |
|---|---|---|
| 信息层 | 谁是重点，谁是支撑？ | 主地图是空间叙事核心；历史图、县域图等提供补充 |
| 关系层 | 谁应该靠近谁，谁应明确分开？ | 省级总览靠近主地图；民营指标、名单和民企地图形成一个主题组 |
| 区域层 | 哪些内容进入左、中、右或上、下区域？ | 左侧核心区、中部说明区、右侧辅助图区 |
| 几何层 | 每块的x、y、宽、高及对齐线是多少？ | 名单的左边对齐中栏，底部不侵占全局来源区 |

**不能跳过前三层，直接讨论某个图向左移多少毫米。**

## 二、把第4步拆成九个可交接的小阶段

以下“成果”是建议的生产交付件，不表示本次已经全部制作完成。

| 子阶段 | 核心决定 | 具体成果实物 |
|---|---|---|
| 4.1 需求盘点 | 每块要讲什么，不能丢什么，容许怎样变化 | 模块需求卡、必保内容表、内容版本号 |
| 4.2 关系组织 | 谁是主角，谁与谁成组，谁依赖谁 | 主次表、相邻关系表、硬约束清单 |
| 4.3 空间建模 | 可用版心和各模块最低空间需求 | 版心参数表、模块尺寸试样、空间预算表 |
| 4.4 候选构图 | 主图放哪里，整版采用哪种大结构 | 两至三张同条件的低保真候选稿 |
| 4.5 区域分配 | 各栏宽度、各组高度、共享对齐线 | 分区草图、模块占位框、容量冲突记录 |
| 4.6 真实内容试装 | 候选位置能否容纳真实标题、标注和名单 | 关键局部试样、真实内容整版试排稿 |
| 4.7 诊断与回调 | 是模块内部问题，还是内容/整版结构问题 | 问题单、调整前后对照稿、删改确认单 |
| 4.8 比较与确认 | 哪个方案在满足约束后更合适 | 方案比较记录、审阅意见、布局确认记录 |
| 4.9 布局交接 | 哪些参数冻结，哪些变化需要重新试排 | 模块定位表、版式规则、版本基线、变更触发清单 |

这九项可以在实际工作中合并文件，但不能省略关键决策。

## 三、第一件事不是画格子，而是给每个模块建立“需求卡”

### 1. 需求卡应记录什么

对M01—M11逐一填写：

1. 模块回答的问题与内容优先级。
2. 必须出现的文字、图形、字段、单位、年份。
3. 当前真实内容量：字数、条目数、最长名称、年份数量、地图标注密集区。
4. 表达方式和可选变体：横图/竖图、单列/双列、短文/指标条等。
5. 最低可读尺寸的试样结果；没有测试时明确标“待测”，不能凭空填一个通用字号。
6. 形状偏好与限制：地图保持地理形状；历史图需要横向轴线；名单受列宽约束。
7. 必须随行的标题、图例、单位、说明、局部来源等。
8. 应相邻或不应混淆的模块。
9. 允许调整什么、由谁批准；哪些内容不能由设计人员直接删除。

**一个模块的占位面积不是图形本体的面积，而是完整阅读单元的面积。**

例如M07不是“一张浙江轮廓图”，而是“模块标题＋地图＋县区标注及引线＋分档图例＋单位和必要说明”。只按地图轮廓留框，后面必然会挤压相邻模块。

### 2. 本案例的关键需求

| 模块 | 主要空间约束 | 优先验证的内容 | 可讨论的调整 |
|---|---|---|---|
| M01 标题导语 | 标题识别度、导语真实行数 | 完整导语是否把左上总览带撑高 | 缩写导语、调整标题与导语组合；不必做成通栏大标题 |
| M02 省级总览 | 文案与环图的组合宽度 | 数值、单位、环图外标注 | 文图并列或上下组合 |
| M03 主要省份GDP | 类别数、轴标与比较所需宽度 | 真实省名、数值、年份、单位 | 改横向条形图或调整展示范围；涉及删省份须内容确认 |
| M04 主地图 | 地理形状、11市环图、密集注记 | 杭州—湖州—嘉兴附近的真实图符和文字 | 重排标注、调整图符策略、扩大图框；不能拉伸地图 |
| M05 “十四五”成就 | 多组长指标名和成对年份数据 | 最长名称、单位、组标题、上下比较关系 | 改图形形式、提炼叙述、减少重复指标 |
| M06 历史图 | 年份序列和纵轴单位 | 所有年份、双轴标签和图例 | 在核对表达含义后选择双轴或对齐小图 |
| M07 千亿元县图 | 县级标注密度高 | 浙东北密集名称及分档说明 | 引线、分区标注、扩大地图或改变辅助表达 |
| M08 民营指标 | 四项指标、长名称、数值和单位 | 名称与数值能否一眼对应 | 短文与指标条之间转换 |
| M09 企业名单 | 完整名称、排名、多行排布 | 最长企业名，样图所示22个条目的整体容量 | 单列/双列，核准简称，或经批准改变展示范围 |
| M10 民企地图 | 地图＋底色图例＋方格图例 | 浙北方格图符、地名及图例 | 图符编排、图例位置、地图区分配 |
| M11 图例来源等 | 局部随行要素与全局页脚分开 | 哪条说明解释哪张图 | 局部图例靠近所属地图；全局来源和落款统一预留 |

### 3. 最小尺寸不是先填一个固定数，而是做样件测出来

以企业名单为例：

- 取真实名单中较长的企业名称，带上排名框、列间距和拟用字体做试样。
- 比较单列与双列：双列减少高度，却增加总宽度需求；窄列下长名称换行，又会把高度增加回来。
- 记录在目标阅读条件下能接受的列宽和行距。
- 用这个结果反过来约束中栏宽度，而不是先给名单一个很窄的框，再要求它“想办法放进去”。

以主地图为例，则应先做北部密集区试样。省界轮廓看起来放得下，并不说明里面的环图、地名和数字能读清。

## 四、第二件事：建立主次、主题组和相邻关系

### 1. 本案例可以建立四个主题组

- **G1 核心组**：M01标题导语、M02全省总览、M03省际比较、M04主地图。回答“讲什么、全省多大、全国处于什么位置、省内怎样分布”。
- **G2 发展解释组**：M05成就、M06历史变化。分别解释发展质量和时间变化；相关，但不必硬挤在同一栏。
- **G3 县域专题组**：M07千亿元县图及紧邻的解释、图例。是对省市尺度主图的进一步补充。
- **G4 民营经济组**：M08指标、M09头部企业名单、M10民企地图。回答“总体规模、头部企业、空间分布”。

这是内容组织建议，并非必须把每组都用边框框起来。邻近、共用标题样式、对齐和间距也可以表示成组。

### 2. 区分“硬约束”与“软偏好”

**本项目一旦确认就必须满足的硬约束**可以包括：

- 已确定的版心、成品安全范围与必保内容。
- 地图不能为了适配矩形而随意拉伸、裁掉必要范围。
- 数据、单位、图例必须能正确对应；不发生文字遮挡和关键内容丢失。
- 已确认的目标可读性条件。
- 修改内容和统计表达必须经过相应负责人确认。

**可权衡的软偏好**包括：

- M02尽量靠近M04，形成“全省总量—市域分布”的联系。
- M08、M09、M10尽量集中，减少同一主题散落。
- M07与M10的图框在右侧形成稳定对齐关系。
- M03与M06两个统计图可以呼应，但不必相邻。
- 左上形成清楚入口，主地图保持显著的视觉权重。

把所有“最好靠近”都当作绝对要求，会得到互相冲突的约束；必须承认有的关系优先级更高。

### 3. 阅读顺序不是鼠标拖拽顺序

设计时应优先解决最难安排的主地图、县级图、名单，并不表示读者应该先看它们。

本版可以引导读者先识别标题和全省总览，再看主地图，之后按兴趣进入成就、县域、民营经济与历史变化。但这只是设计意图，不能断言所有读者都会按一个固定“Z形”路线阅读。

**视觉优先级高也不等于占地面积大。** 标题很重要，但不应因此获得比主地图更大的面积。

## 五、第三件事：先建立可用版心，再提出两至三种整体骨架

### 1. 先确认容器，而不是从图片像素直接推纸张

需要明确：成品宽高、版心、安全范围、边饰或框线是否占用版面、全局来源区，以及实际观看方式。

现有JPG能帮助判断横向单版比例，**不能替代正式开本和裁切范围确认**。没有确认时，可以按参考比例做关系草图，不能声称已确定印刷毫米数和最终字号。

### 2. 优先安排“最难移动、最难缩小”的部件

这个案例中：

- M04主地图是最大的空间承诺。
- M07县级图有密集名称，不应因为它是辅助图就被无限压缩。
- M09企业名单对最小列宽敏感。
- M05成就模块有真实文字和对比图，决定中栏是否可行。

因此实际构图不是依次从M01摆到M11，而是先检查这些关键模块能否共存。

### 3. 可以提出三种候选骨架

下面是建议用于比较的方案，不是已经做过实测的评分结果。

| 候选 | 整体安排 | 可能优点 | 需要验证的代价 |
|---|---|---|---|
| A 主地图靠左上，统计图压在左下 | 类似来源标注参考中可见的配置；中栏成就，右栏辅助地图 | 主地图尽早出现，容易保留原有部件 | 左下历史与省级总览截断主图区域；总览可能显得滞后；底部密度较高 |
| B 左上总览、左下主地图，中部解释，右侧辅助图 | 接近现有成图的分区方式 | 总览与主图联系紧；右下与中下可形成民营主题组 | 左上总览过高会压缩主图；中栏能否容纳成就和名单要实测 |
| C 主地图居中，两侧安排说明和辅图 | 核心地图居中，两翼分配其他内容 | 中心性强，可能强化主图 | 横向空间被两翼瓜分；辅图和企业名称可能过窄；总览与主图联系可能被拆散 |

比较时应使用相同版心、相同必保内容和大体一致的阅读条件。如果某个方案删掉了不少内容，应明确标注，不能把“删得更多”伪装成“同等内容排得更好”。

### 4. 低保真方案要看什么

暂不争论底纹、渐变和装饰，先检查：

1. 主图是否仍然是主角。
2. 关键内容是否都有容器，图例和来源是否已被计入。
3. 主题有没有被不必要地拆开。
4. 是否出现明显不可能容纳真实内容的窄栏、矮框。
5. 留白和信息密度是否集中失衡。

这一轮淘汰的是结构问题，不能据此宣布文字已经可读。

## 六、第四件事：协商各区宽高，不能平均分三栏

### 1. 先分组的区域，再分组内模块

以方案B为例，先分：

- 左区：标题、导语、省级总览、省际比较、主地图。
- 中区：成就、民营指标、企业名单。
- 右区：历史图、千亿元县图、民企地图。
- 全局底部：来源、必要说明与落款。

然后再讨论左区中M02与M03并排还是上下；中区M05、M08、M09各占多少高度。**不要一开始就将11块作为互不关联的矩形分别拖动。**

### 2. 用约束而非固定百分比决定栏宽

设可用内容区宽度为W，左、中、右区宽度为WL、WM、WR，两个分区间距为G1、G2，则：

`WL + G1 + WM + G2 + WR = W`

但还必须满足：

- `WL`能支持M04及左上总览组合。
- `WM`不能小于M05、M08、M09所需最小宽度中的最大值。
- `WR`不能小于M06、M07、M10所需最小宽度中的最大值。

如果这几个需求加起来超过W，说明当前内容和表达方案在这个版心里不可行。需要改变表达、内容量、构图或输出尺寸，**不是通过全部缩小到不可读来宣布完成**。

### 3. 高度也要列预算

- 左区：标题导语与总览组合＋主地图＋组间距，应不超过可用高度。
- 中区：成就＋民营指标＋企业名单＋各间距，应不超过可用高度。
- 右区：历史图＋县域地图＋民企地图＋各间距，应不超过可用高度。

注意，标题、轴标、局部图例和说明已经包含在各模块高度中；全局页脚不能在末尾重复挤入。

一个典型连锁影响是：为了名单加宽中区，会压缩右区；右区变窄使县域地图变小，县名可能更挤，或者使图例换行增加高度；随后历史图或民企图的位置也要变化。**位置是相互依赖的，不是11个独立坐标。**

### 4. 地图适配要检查真正的限制方向

如果某个地图占位外接形状的宽高比为r，候选框为`Wbox × Hbox`，不变形适配的示意上限是：

`w_fit = min(Wbox, r × Hbox)`，`h_fit = w_fit / r`。

这只是几何检查。实际还要扣除标题、外部标注和图例所需空间，并按目标尺寸重排注记。

因此，当宽度已经是瓶颈时，继续增加地图框高度不一定能把地图放大；反之亦然。不能只看“面积变大了”就以为可读性必然改善。

地图等比改变使用尺寸后，还应同步核对比例尺表示、图符、字级和线宽。不能只缩放一张位图而忽略最终阅读条件。

## 七、第五件事：逐个解释当前模块为什么可以放在这个位置

以下是对现有成图位置的分析，而非原设计者动机的断言，也不表示它是唯一或已经验证最优的方案。

### M01 标题与导语：左上，建立入口，不必占满通栏

**位置逻辑**：左上能够将主题识别与左侧省级总览连在一起；标题和导语组成入口，不与右侧历史图争夺同一大标题横带。

**为什么不直接铺满整版顶端**：通栏大标题会同时压低中栏和右栏，减少辅助图的可用高度。标题的重要性可以由字形、字重、对比和周边留白体现，不必靠大面积。

**怎样确认**：放入最终导语，检查行数；如果导语增多使整个左上区变高，应先审查重复内容或组合方式，不能无止境向下推主地图。

### M02 省级总览：标题下方、主地图上方

**位置逻辑**：先交代全省经济规模和产业结构，再进入各市分布。这里的省级环图与主图中的城市环图形成表达上的联系。

**为什么不放页脚附近**：若它被定位为核心总览，放在很低的位置会削弱其作为主图背景的作用；但如果项目改为“先看地图、再查统计”，低位也不是绝对错误。

**怎样确认**：试装真实总览文字和环图外标注，检查是否与M03争夺横向空间；必要时改成更紧凑的文图组合。

### M03 主要省份GDP：省级总览右侧、主地图上方

**位置逻辑**：与M02一起回答“浙江的规模和相对位置”，形成一块总览区域；柱图较适合利用这一块横向空间。

**为什么不塞进中栏**：中栏已经承担多组说明和名单，横向类别图再进入会增加列宽冲突，也会割裂民营内容。

**怎样确认**：用完整省名、年份、单位、坐标与真实类别数试排；如果只有空柱子时好看、加轴标后挤满，就要重新分配宽高或换图形。

### M04 主地图：左侧大区，下缘延伸接近全局页脚

**位置逻辑**：它既是主题空间表达的核心，又是最难压缩的模块，应拥有连续而非零碎的空间。上方的M01—M03负责解释，主图负责空间展开。

**为什么不是正中央就一定更重要**：中心位置只是强调方式之一。左侧的面积、连续空间和图形重量也可以建立主次。若居中后所有辅助内容都过窄，中心方案未必更好。

**怎样确认**：检查省域范围、沿海岛屿、外部标注、北部密集环图与地名、局部图例；不能只检查省界是否落在矩形内。

地图轮廓外的空白并非都可随便填充。海域、离岸要素、图例和视线缓冲有其作用。可以讨论在自然空白中安放局部说明，但必须检查边界、引线和归属是否清楚。

### M05 “十四五”成就：中栏上部

**位置逻辑**：多个成就主题适合自上而下阅读；中栏将主地图和辅助专题联系起来，也保留了下方民营主题的完整区段。

**为什么不能只把它看成一块长方形文字**：长指标名称、年份对比、小图形、分组标题都会影响所需宽高。宽度减少可能导致换行，反而增加高度。

**怎样确认**：优先试最长指标名和最复杂的对比组。若明显超高，可经确认提炼文案、合并重复信息或调整小图形式，而不是不断挤压M08、M09。

### M06 历史变化：右上

**位置逻辑**：历史图是一个较独立的统计阅读单元，右上可提供连贯的横向轴线空间；放在右侧地图上方，也避免在主地图下面再切出一整条统计图带。

**需要承认的取舍**：它与M02、M03并不直接相邻。这里是在“所有统计图集中”和“保护主图连续空间、满足辅助图尺寸”之间作取舍，而不是证明历史图天然就应该放右上。

**怎样确认**：真实年份、双轴单位、图例全部进入后仍能读清；若改成两个对齐小图，必须重新计算右栏高度，不能假定原框仍够用。

### M07 千亿元县图：右栏中部

**位置逻辑**：作为市域主图的县域补充，与右下同为省域范围的民企地图形成辅助地图序列。其位置还受M06底部和M10顶部的共同约束。

**不能仅靠什么来判断**：两张辅助图“差不多大”“边缘对齐”不代表都可读。县名密集程度不同，M07可能需要更多注记空间。

**怎样确认**：使用密集区真实名称、引线、分类符号、图例和说明测试。若标签放不下，先处理注记方案并检查地图框；仍不够，就调整右栏分配。标题的“千亿元”门槛语义应先确认，不能照搬存在疑问的样图文字。

### M08 民营经济指标：中栏中下部

**位置逻辑**：位于M09名单上方，形成“总体规模—头部企业”的层次，同时接近右下M10地图，构成一个跨栏主题组。

**为什么不是随便插在成就模块内部**：民营经济有独立标题、口径和后续名单/地图，拆散后会削弱读者对主题边界的识别。

**怎样确认**：四项指标名称与数值一一对应，单位完整；指标条的紧凑程度以不损害含义为前提。

### M09 企业名单：中栏底部

**位置逻辑**：详细查询材料放在总览指标之后；与右下民企地图在空间上相邻，使文字明细和空间分布有联系。

**为什么不能哪里剩空间就放哪里**：名单的真实列宽、行数和标题会形成硬容量需求。设计时必须先估算和试装，再决定中栏剩余高度，而不是最后把它塞进一个空隙。

**怎样确认**：放入完整企业名称和排名，检查换行、列间对应、底部说明、读序及距页脚的安全空间。它与M10涉及的“前100强”和“500强”并非同一统计范围，靠近时更要把标题说清。

### M10 民企地图：右下

**位置逻辑**：与M08、M09组成民营经济组，与M07保持辅助地图的组织秩序；右下不是“次要到可以忽略”，而是这一主题的空间展开位置。

**怎样确认**：检查底色分级和500强方格符号是否有各自清楚的解释，北部符号是否重叠，图例是否侵入全局页脚。如果图符太密，需要处理符号编排与地图尺度，而不仅是下移标题。

### M11 图例、来源与落款：拆成局部随行与全局底部两部分

**位置逻辑**：M11是管理上的汇总编号，不意味着所有说明都放成一个页脚模块。

- M04的颜色、产业扇区、必要的图符大小说明，靠近M04。
- M07的县级GDP分档图例，靠近M07。
- M10的企业数量设色与500强方格图例，靠近M10。
- 全局来源、制作落款和本项目要求的说明，统一安排在全局底部。

**怎样确认**：读者是否无需猜测就能知道每个图例解释哪张图；移动地图时，所属图例和说明也一起移动并复核。

## 八、两张参考图的差异，能够说明什么

两张图并没有附带可核验的完整修改记录。下表只将可见差异与可能的布局收益分开列出。

| 对象 | 来源标注参考中可见 | 现有成图中可见 | 可以讨论的布局收益，不是已证实动机 |
|---|---|---|---|
| 主地图 | 左上开始，下方另排历史图、总览等 | 左上先排导语和总览，主地图在其下延伸接近页脚 | 将“总览—空间展开”组织在同一核心区，减少主图下方横带 |
| 历史图 | 左下 | 右上 | 解除对左侧底部空间的占用，利用右上统计图区 |
| 省级总览与环图 | 左下偏中 | 左上 | 让省级数据与主图的联系更直接 |
| 主要省份GDP | 未见现有成图中同样的独立模块 | 左上总览旁 | 增加全国比较，但需要为它重新预算空间 |
| 千亿元县说明 | 右上有较大文字与小图示区 | 右上改为历史图，保留右中县域地图 | 避免相关文字与地图占据两块过大的区域；但要检查有无丢失必要信息 |
| 民营经济概况 | 以段落为主 | 四条指标式表达 | 降低段落占高，强化名称与数值对应 |
| 成就模块 | 更多小图和较长纵向内容 | 采用更紧凑的组合 | 为民营主题保留空间，但内容取舍仍需确认 |
| 城市照片 | 左下有照片 | 未见照片 | 可能释放非核心图像空间；不证明照片在任何项目都应删除 |

这里最值得注意的是：**变化不仅是位置变化，还包含内容删减、内容新增和表达形式变化。**

如果要求“所有文字、图表形式、模块大小都完全不动，只交换坐标”，很难得到现有成图这样的结构调整。

## 九、用一次完整推演说明：历史图的位置怎样影响整版

以下是教学推演，不是对原始制作过程的历史复原。

### 回合1：把素材放齐，暴露冲突

先按来源标注参考的配置思路摆放：主地图左上，历史图和总览在左下，成就在中部，县域说明与两幅辅助图在右侧。

此时应提出的不是“漂亮不漂亮”，而是：

- 省级总览为何出现在主地图之后，是否符合本项目阅读目标？
- 左下统计横带是否妨碍主地图获得需要的空间？
- 右上县域说明是否与县域地图重复？
- 中栏成就、民营段落和完整名单能否同时容纳？

**成果**：一张完整但允许粗糙的配置稿，加一份空间冲突清单。

### 回合2：明确结构目标，而不是先移动一个小图

提出“省级总览靠近标题，左侧形成总览＋主地图”的结构目标。

这意味着先为左上总览带和左下主地图保留整体空间，历史图不能再默认拥有原来的左下位置。此时历史图可以有多个候选去向，而不是只有右上一种答案。

**成果**：至少两张调整后的区域草图，并记录各自牺牲了什么。

### 回合3：验证右上是否适合接收历史图

右上能不能腾出，取决于县域文字说明是否可以提炼、合并至县域模块或删去重复内容。这是内容决策，不能由设计人员为了塞图自行决定。

获得内容确认后，将历史图带完整轴标和图例放入右上，再检查右中县域图是否还保有足够高度。

**成果**：调整过的文案版本＋右栏真实内容试样。

### 回合4：检查新增总览是否又挤压了主地图

历史图移走并不保证主地图就变好，因为左上新增省际比较和总览带也占用高度。

要同时检查：左上是否过高；主地图的限制来自宽度还是高度；北部环图和沿海标注是否可读。必要时再调整总览组合，而不是只庆祝“历史图成功搬走”。

**成果**：左侧总览与主地图的联动试样，以及关键密集区校样。

### 回合5：让民营主题完整落位

中栏为M08、M09预留实际容量。若M05过高，先讨论成就内容的取舍与小图表达；若民营概况段落重复信息较多，可经确认改为指标条。

这时M08、M09与右下M10形成主题联系，但仍要验证名单的真实名称宽度，以及M10的双重图例是否清楚。

**成果**：民营主题跨栏试样＋内容调整记录。

### 回合6：整版复查后才能确认

局部都能放下，还要检查：视觉主次、主题跳转、间距、留白、颜色强弱、正文与来源边界等。

若没有正式输出尺寸，此时只能确认关系型草图，不能确认印刷可读性。条件齐备后，再按目标输出尺寸和观看方式检查，并形成布局确认记录。

**成果**：可追溯的整版试排稿＋布局基线，不是只有一张没有版本说明的JPG。

## 十、试排时具体检查什么，发现问题后怎样回调

### 1. 做三种尺度的检查

| 检查层次 | 看什么 | 不能替代什么 |
|---|---|---|
| 缩略整版 | 入口、主次、区域密度、主题是否散乱 | 不能证明小字可读 |
| 目标输出尺寸 | 字级、图例、地图线条、真实阅读负担 | 不能只凭高分辨率截图或可放大观看来通过 |
| 局部放大 | 遮挡、引线对应、地名、数字和图符细节 | 放大后读得清，不代表实际尺寸读得清 |

印刷用途应依据正式成品尺寸检查纸样或相应校样；屏幕用途则按照约定终端、显示尺寸和交互方式检查。软件的“100%缩放”不总等于纸张的真实物理尺寸。

### 2. 不只检查“有没有溢出”，还要检查“有没有误解”

可让没有参与设计的人完成简短查找任务，例如：

- 找出全省经济规模与三产业结构。
- 找到某市GDP总量与人均GDP所属档位，并说明两者分别由什么图形表达。
- 解释千亿元县图的分类含义。
- 找到民营企业总体规模，并区分前100强名单与500强地图符号。

这些是建议的验证任务，不是本次已实施的测试。观察读者寻找错误、混淆图例或反复跨区时，应记录原因，而不是只问“你觉得好不好看”。

### 3. 问题要分类处理

- **局部排布问题**：引线交叉、标题离图过远、图例位置不清。先在模块内部调整。
- **模块容量问题**：完整名单放不下、历史图轴标拥挤。调整宽高或表达形式。
- **内容容量问题**：成就指标过多、长文反复讲同一信息。交内容负责人讨论提炼、合并和删减。
- **整版结构问题**：多个关键模块都需要同一块空间。返回候选构图，不要靠十几次零碎移动掩盖根本矛盾。
- **输出条件问题**：既定开本无法满足全部必保内容及可读要求。需要重新讨论内容规模或成品条件。

这些动作不是不可逆的流水线；诊断清楚后可以直接回到对应层级。

### 4. 问题单应能指导下一次动作

推荐字段：

`问题编号｜模块｜内容/图件版本｜位置｜现象｜影响｜原因判断｜建议动作｜责任人｜需谁确认｜复测结果｜状态`

例如：“M09第二列长企业名换行，导致名单超出中栏底线”，比“中间有点挤”有用得多。处理后还应复查：加宽中栏是否缩小了右侧地图，是否又造成县名冲突。

## 十一、最后才是坐标：如何形成可执行的定位表

### 1. 坐标来自已确认的关系、容器和网格

以可用内容区左上角为原点：

- 左区起点：`xL = 0`。
- 中区起点：`xM = WL + G1`。
- 右区起点：`xR = WL + G1 + WM + G2`。
- M09的顶部：`y09 = y08 + h08 + g08_09`。
- M10的顶部：`y10 = y07 + h07 + g07_10`。

这里的h包含模块完整外框，而非仅图形本体；g是经确认的组间距。组内还可以建立较细的栅格和基线。

这样得到的坐标有因果关系：若M08增加一行，M09会下移；若不允许它下移，就要回调M08或其他模块。不是每个模块任意填写一组互不关联的数值。

### 2. 逐个模块记录的不应只有x、y

| 字段 | 应记录内容 |
|---|---|
| 模块身份 | M01—M11；必要时M11拆分成各地图随行要素与全局页脚 |
| 所属主题组 | 总览/主图、成就、县域、民营等 |
| 内容版本 | 文稿、数据表、地图和图表文件的对应版本 |
| 几何参数 | 原点、单位、x、y、宽、高、内边距、与邻块间距 |
| 对齐约束 | 与哪条栏线、哪个标题、哪个图框对齐 |
| 最低空间条件 | 已验证的最小宽高、字级和关键密集区条件 |
| 内部组成 | 标题、单位、图例、来源、说明、图形本体 |
| 裁切/缩放规则 | 哪些可缩放、哪些需重新制图，哪些不得裁切 |
| 放置理由 | 为什么在这里；采用方案放弃了什么 |
| 调整权限 | 可直接微调的范围，需内容/制图负责人批准的变化 |
| 检查状态 | 待试排、试排有问题、已复核、已确认等 |

现有蓝图中的框位置是按样图反向估计的视觉范围，不具备上述完整的生产参数和验证状态。它适合讨论结构，不能直接作为原作者的精确定位表。

### 3. 哪些变化应触发重新试排

- 增加企业名单行数或更换为更长的正式名称。
- 历史图增加年份、改用不同轴线形式。
- 县域分档或标注名单变化。
- 主地图新增环图、改变图符大小编码或底图范围。
- 导语、成就模块明显增字。
- 某个图例增加类别或更换单位。
- 更换字体、成品尺寸、输出媒介或观看条件。

这些变化不一定全部推倒重来，但必须检查受影响的模块及相邻区域。

## 十二、谁来定，以及做到什么程度才算“位置确定”

| 角色 | 对位置决策承担的责任 |
|---|---|
| 内容统筹 | 确认主次、必保信息、成组逻辑；批准删改和内容换形后的含义 |
| 制图与可视化 | 确认地图形状、图符、注记、轴线、图例等表达限制；验证缩放或改形后的正确性 |
| 版式设计 | 提出候选构图，测算容量，组织模块关系，执行试排与坐标化 |
| 项目确认者 | 在约定范围内确认选用方案、未解决项和进入制作的条件 |

内容负责人不需要未经试排就指定所有毫米坐标；设计师也不能为构图好看擅自删企业、改统计口径或隐藏必要图例。

**第4步可进入第5步的条件**是：

1. 主辅关系和主题分组已确认。
2. 候选方案的取舍有记录，关键空间冲突已有明确处理方案。
3. 高风险模块用真实内容做过试装，未验证部分明确列出。
4. 模块外框、随行要素、留白和全局底部空间都有安排。
5. 内容调整已得到相应确认，图文版本对应。
6. 可执行的布局基线和变更规则已经交接。

这不替代第5步完整制作、第6步联合审校和第7步输出检查。若正式开本或关键数据未齐，可以先交接低保真布局，但应标明它还不是通过实际尺寸检验的布局定稿。

## 最后概括

对这张浙江“经济发展”专题图，模块位置的确定可以概括成：

> **先保主地图的连续空间，再围绕阅读问题组织总览、成就、县域和民营主题；用真实内容测出各组的空间需求，比较整版方案，在试排中联动调整内容、形态和位置，最后把选定方案固化为坐标、规则和确认记录。**

决定位置的不是“这里恰好有空白”，而是四件事共同成立：**内容上讲得通，几何上放得下，阅读上看得清，制作上可执行。**
